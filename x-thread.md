# X thread — the three-path framework (draft, use or ignore)

1/ Your AI agent makes hundreds of decisions an hour. Today every one of them takes one of two paths — and both are failure modes.

2/ Path A: the unconscious decision. The agent picks a schema, a library, an interpretation — without ever registering that a choice existed. Failure analyses of coding agents are full of this: confident motion down an unexamined branch.

3/ Path B: the full stop. The agent notices the choice and halts to ask you — including questions the docs already answer. Enough stops and "AI-empowered" quietly becomes "AI-supervised."

4/ The missing mode is Path C: deliberate autonomous resolution. Notice the decision. Run a procedure. Document the call — rationale, alternatives, confidence, reversibility. Keep moving.

5/ Path C isn't a capability, it's metacognition + discipline. Which is why it needs a procedure: the Decision Ladder. (1) consult the docs (2) reason with the right specialist lens (3) make the call and document it (4) escalate — distilled — only for the irreversible or mission-level.

6/ The rule that makes it work: each rung must be genuinely exhausted before climbing. And the stance that makes it cultural: Rung 3 is not a failure. A documented judgment call is autonomous competence, whether or not it proves optimal.
